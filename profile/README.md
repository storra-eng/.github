# Storra

Welcome to Storra's GitHub organisation.

## About Us

[Storra](https://getstorra.com) is the impact marketplace where brands fund real stories, creators tell them, and charities benefit from them.

People remember stories, not ads. Charities are the largest untapped source of powerful stories on earth - real people, real stakes, real transformation. We bring brands, creators, and charities together so the most commercially powerful thing a brand can do is also the most meaningful: fund a real story where their product is the reason the transformation happens.

20,000+ charities. 50,000+ creators. One marketplace turning marketing budgets into measurable impact.

## AI-First Engineering

We're an AI-first engineering team, leveraging AI tools throughout our development workflow:

- **Claude Code** for AI-assisted coding
- **Spec Kit** for spec-driven feature development
- **Gemini** and **Ollama Cloud** powering our production story-generation pipeline

## Our Tech Stack

**Frontend**
- React 19 with Vite 7
- TypeScript
- Tailwind CSS
- shadcn-ui (Radix)
- TanStack React Query
- Framer Motion

**Backend**
- Supabase (Postgres, Auth, Storage, Realtime) with row-level security throughout
- Encore.ts for our function tier, being migrated from Deno edge functions (which still run alongside it)
- Cloudflare Workers for edge services (geolocation, proxies)

**AI & Video**
- Google Gemini (primary), Ollama Cloud (secondary)
- Remotion for programmatic video rendering

**Agents & Automation**
- Cyrus for Linear-driven Claude agents
- Paperclip for our internal autonomous-agent stack

**Testing & Infrastructure**
- Vitest for unit tests
- Playwright for E2E tests
- Encore Cloud (staging and prod) for the function tier
- Lovable for frontend deployment
- GitHub Actions for CI
