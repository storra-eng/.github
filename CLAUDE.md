# CLAUDE.md

This repo is the storra-eng organisation's public `.github` repo. It holds no application code, only the public org profile.

## Layout

- `profile/README.md` - rendered by GitHub as the public organisation profile.
- `README.md` - describes the repo itself.

## Making changes

Edit the Markdown directly and push to `main`. See GitHub's docs on customising an organisation profile:
<https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile>

## Documentation vs code

When a repository's documentation and its existing code disagree, follow the conventions in the existing code. In your final reply, list each inconsistency you found between the documentation and the code.
